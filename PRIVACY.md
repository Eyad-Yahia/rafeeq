# Privacy Policy

This library runs entirely client-side by default.
- **No Tracking**: We do not collect telemetry, analytics, or user behavior.
- **Voice Data**: If using the default Voice Recognition, audio is processed by the browser's native engine (which may send data to Google/Apple depending on the OS).
- **Custom Providers**: If you use a custom AI provider (e.g. OpenAI), you are responsible for outlining data usage to your end users.
